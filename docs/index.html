Digital radio alarm

A homemade bedside alarm clock built around internet radio streaming: e-ink clock/date display with a "now playing" bar, small speaker, top-down light for reading the display in the dark, and an alarm that fades a chosen station up to full volume instead of jumping straight there. Runs on a Raspberry Pi over WiFi.

Early build — hardware not wired up yet, station management working locally

What it does

  • Shows the time and date on an e-ink display, plus a small "now playing" bar for the current station.
  • Sets an alarm for a specific time and a specific internet radio station.
  • When the alarm fires, that station starts playing and ramps up to full volume over roughly a minute rather than jumping straight there.
  • A top-down light (like the old clip-on Kindle case lights) illuminates the e-ink screen in the dark.
  • Search and favorite stations from a phone, from anywhere on the home network.

Design decisions so far

  • No hosted backend. Station discovery uses the free, open Radio Browser API; stations actually used are kept in a local favorites file on the Pi itself.
  • Alarm logic runs entirely on-device — alarm time and chosen station are stored locally, no network round-trip needed to fire an alarm.
  • Stream playback shells out to mpv rather than using a Python audio library directly.
  • Station search runs server-side, on the Pi — Radio Browser's API requires DNS-based mirror discovery that browser JavaScript can't do, so the Pi does the lookup/retry and serves its own small local management page instead.

Still open

  • Physical input method — rotary encoder + buttons is the working assumption, not yet confirmed.
  • Exact e-ink panel model — needs to support partial refresh; affects enclosure dimensions.

Repo structure

src/
  main.py          entry point, wires everything together
  alarm/           alarm scheduling + persistence
  audio/           mpv subprocess wrapper, volume ramp, now-playing metadata
  display/         e-ink driver wrapper + UI layout
  input/           rotary encoder / button handling
  light/           PWM front-light control
  stations/        Radio Browser client + local favorites
  web/             local management page - search + favorite stations from your phone
data/
  favorites.json   saved stations
systemd/
  digitalradioalarm.service       runs main.py on boot
  digitalradioalarm-web.service   runs the management page on boot

Status detail

  • Working: station search + favorites (Radio Browser API, local web UI).
  • Not yet built: alarm scheduling, audio playback, e-ink display, physical input, light control — all pending the hardware decisions above.
